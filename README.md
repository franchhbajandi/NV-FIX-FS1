## 📦 Content Intake Protocol (Zero-Paraphrase JSON Pipeline)

All client text arrives as structured JSON files prepared and checked by the client’s strategy partner. The application imports these files programmatically and **never** retypes, paraphrases, shortens, or edits client wording in component code:

- **Episodes (`01`–`06`)**: `src/content/episode-01.json` through `src/content/episode-06.json`
- **Institutional Content**: `src/content/institutional.json`, `src/content/philosophy.json`, `src/content/appendices.json`
- **Photo Metadata**: `src/assets/photos/photos.json`

### Replacing a Content File
When a new version of a file is supplied:
1. Replace the corresponding JSON file in `src/content/` (or `src/assets/photos/photos.json`).
2. Run `npm run verify-content` (or `npm run build`, which runs `verify-content` automatically).
3. For every non-pending **question**, **answer**, **table cell**, and **caption**, `npm run verify-content` compares the exact **word count** and **SHA-256 hash** between the source JSON and:
   - **(a) the rendered Digital DOM**, and
   - **(b) the rendered Print Edition (`/print`)**.
   Any mismatch fails the build with a detailed diagnostic report.

## 📸 How to Add a Photo (Plain Language Guide)

Adding photos to the Field Study 1 portfolio is automated through `src/assets/photos/` and `src/assets/photos/photos.json`:

1. **Protect Learner Privacy First**: Permanently blur or crop any identifiable student faces before saving the image.
2. **Name the File by Convention**: Use the episode number, a two-digit item number, and a descriptive slug (`.webp`, `.jpg`, `.jpeg`, `.png`, `.avif`, `.svg`):
   - `ep04-01-instructional-board.webp` *(or `ep4-01-instructional-board.webp`)*
   - `ep02-01-school-corridor.webp`
   - `ep05-01-classroom-furniture.webp`
3. **Place the Image in `src/assets/photos/`**: Drop the image file into `src/assets/photos/`.
4. **Update `src/assets/photos/photos.json`**: Add or update the matching key with `caption`, `alt`, `credit`, and `"status": "COMPLETE"`.

## 📄 Archival A4 PDF Generation (`npm run pdf` & `/print`)

1. **Automated Playwright CLI Export (`npm run pdf`)**:
   - With the dev server running (`npm run dev`), run `npm run pdf` to export `public/Bajandi_FS1_Portfolio.pdf` from `/print`.
2. **Browser Print Fallback (`/print`)**:
   - Open `/print` (or click **Open print edition** in the Tools menu), press `Ctrl/Cmd+P`, select **Save as PDF**, paper size **A4**, and enable **Background graphics**.
